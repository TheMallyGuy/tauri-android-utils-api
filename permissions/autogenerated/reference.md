## Default Permission

Default permissions for android-utils plugin

#### This default permission set includes the following:

- `allow-get-installed-apps`
- `allow-get-user-installed-apps`
- `allow-get-app-tv-banner`
- `allow-get-wifi-signal`
- `allow-get-bluetooth-status`
- `allow-open-settings`
